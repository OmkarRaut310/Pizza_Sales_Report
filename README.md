#🍕 Pizza_Sales_Report_Dashboard  

📌 Project Description  
This project is an end-to-end **data analytics dashboard** built using **Excel, SQL Server Management Studio 22, Power Query, Power BI, and DAX formulas**. It provides a comprehensive view of pizza sales performance, customer behavior, and product trends for the period **Jan 2015 – Dec 2015**.



🛠️ Tools & Technologies  
- **Excel** → Initial dataset preparation and cleaning.  
- **SQL Server Management Studio 22** → Database creation, queries, and structured data management.  
- **Power Query** → Data transformation and shaping.  
- **Power BI** → Interactive dashboard and visualization.  
- **DAX** → Custom measures and KPIs for deeper insights.  



📊 Key Metrics  
- **Total Revenue:** 817.86K  
- **Average Order Value:** 38.31  
- **Total Pizzas Sold:** 49,574  
- **Total Orders:** 21,350  
- **Avg Pizzas per Order:** 2.32  



🔎 Insights & Highlights  
- **Busiest Days & Times:** Friday & Saturday evenings show peak orders.  
- **Monthly Trends:** Highest orders in **July** and **January**.  
- **Category Performance:**  
  - *Classic* pizzas contribute maximum sales.  
  - *Chicken* pizzas lead in percentage share (26.91%).  
- **Size Performance:**  
  - *Large pizzas* dominate sales (45.89%).  
- **Best Sellers:**  
  - *Thai Chicken Pizza* → Highest revenue contributor.  
  - *Classic Deluxe Pizza* → Highest quantity sold.  
- **Worst Sellers:**  
  - *Brie Carre Pizza* → Lowest in both revenue & quantity.  



📈 Top & Bottom Performers  
- **Top 5 by Revenue:** Thai Chicken, California Chicken, Classic Deluxe, Spicy Italian, Barbeque Chicken.  
- **Bottom 5 by Revenue:** Spinach Supreme, Mediterranean, Spinach & Cheese, Green Garden, Brie Carre.  
- **Top 5 by Quantity:** Classic Deluxe, Barbeque Chicken, Hawaiian, Pepperoni, Thai Chicken.  
- **Bottom 5 by Quantity:** Soppressata, Spinach Supreme, Calabrese, Mediterranean, Brie Carre.  


 🚀 Business Value  
- Identifies **customer preferences** and seasonal demand.  
- Helps optimize **menu offerings** and promotions.  
- Supports **inventory planning** and marketing strategies.  
- Provides actionable KPIs for **sales growth**.
